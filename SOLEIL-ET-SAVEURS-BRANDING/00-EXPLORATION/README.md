# Exploration du logo — Soleil et Saveurs (historique)

- `v8-logo-client-net/` : **votre logo d'origine en version nette**. C'est votre dessin (détouré, agrandi x4 par IA), avec tous les textes refaits en vectoriel. `AVANT-APRES.png` montre le résultat.
- `v7-reproduction-logo-client/` : première tentative, une reproduction 100 % vectorielle du logo fourni. **Non retenue** : le dessin redessiné était moins beau que l'original.
- `v6-apercu-B1-T3/` : aperçu du paysage B1 avec la typographie T3, sans l'arche B5.
- `v5-variante-B1-lever-du-jour/` : l'emblème final avec le paysage B1 au lieu du papier découpé. Variante **non retenue** : le logo officiel reste le papier découpé.
- `v4-piste-B/` : piste B retenue, six versions enrichies. La **B5 « Arche titrée »** a été choisie, puis modifiée : paysage en papier découpé (B6), bandeau « PRIMEUR DEPUIS 1999 », typographie T3. Le résultat est dans les dossiers 01 à 08.
- `v3/` : exploration élargie, 15 pistes (D → R).
- `v2/` : trois pistes perfectionnées (A, B, C).
- `v1/` : premières planches.
