# Soleil et Saveurs — Piste B « L'Horizon gourmand », version enrichie (v4)

La piste B est retenue. Cette étape propose plusieurs améliorations à choisir et combiner.

## Présentation

`Soleil-et-Saveurs-piste-B-enrichie.pdf` contient 18 diapositives. Le dossier `diapositives/` les reprend en images 3840 × 2160.

## Les six versions du symbole

| Version | Nom | Ce qui change |
|---|---|---|
| B1 | Le Potager au lever du jour | Halo en trois anneaux, champs sillonnés, étal reconnaissable (poireaux, chou, tomate, poire) |
| B2 | Les Sillons | Soleil rayonnant, champs labourés, verger à l'horizon, pomme au premier plan |
| B3 | La Gravure | Hachures façon étiquette ancienne, imprimable en une couleur (noir et blanc fournis) |
| B4 | La Fenêtre des Halles | L'arche devient la verrière d'une halle : les meneaux sont les rayons, l'étal est en vitrine |
| B5 | L'Arche titrée | Emblème : le nom en arc, bandeau « Primeur · Yvelines (78) » |
| B6 | Le Papier découpé | Plans superposés avec ombres portées : un effet de relief |

`Bs` est la version simple, pour les tailles sous 40 px (favicon).

## Autres améliorations

- **Typographie** : quatre réglages de Fraunces dans `logos/piste-typo` :
  - T1 actuelle ;
  - T2 caractère ;
  - T3 avec descripteur ;
  - T4 esperluette.
- **Palette** : élargie à 12 teintes.
- **Illustration de marque** : le panorama « Du champ à votre porte ».

## Fichiers

- `logos/` : SVG, texte vectorisé.
- `sources/` : scripts. Ils s'appuient sur `../v3/sources` (moteur, maquettes, polices).

Statut : en attente du choix (symbole, typographie, illustration), avant la production du kit final.
