# Réseaux sociaux — Soleil et Saveurs

Facebook et Instagram découpent la photo de profil **en rond**. Ces fichiers sont carrés (2048 × 2048) et le logo y tient entièrement dans le cercle : rien n'est coupé.

| Fichier | Usage |
|---|---|
| `photo-profil_embleme_fond-lin.png` | **Recommandé.** L'emblème complet sur fond lin |
| `photo-profil_embleme_fond-vert.png` | L'emblème sur fond vert olivier |
| `photo-profil_symbole_fond-lin.png` | L'arche seule, plus grande et plus lisible en petit (le nom de la page s'affiche déjà à côté) |
| `photo-profil_symbole_fond-vert.png` | L'arche seule sur fond vert |
| `photo-couverture_facebook.png` | Photo de couverture Facebook (1640 × 624). Le logo est centré pour rester visible sur mobile |
| `apercu-dans-le-cercle.png` | Aperçu du rendu en rond |

À l'import sur Facebook, ne zoomez pas : laissez le cadrage par défaut.
